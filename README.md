# 🔐 Random Password Generator

## 📌 About the Project

The **Random Password Generator** is a simple Python project that generates random passwords using uppercase letters, lowercase letters, numbers, and special characters. The current program generates a 12-character password.

This project is designed for beginners who want to practice Python programming concepts and learn how to use built-in modules.

## ✨ Features

- Generates a random 12-character password.
- Includes uppercase and lowercase letters.
- Includes numbers (0–9).
- Includes special characters such as `@`, `#`, `$`, and `!`.
- Uses Python's built-in `random` and `string` modules.

## 🛠️ Technologies Used

- **Language:** Python
- **Modules:** `random`, `string`
